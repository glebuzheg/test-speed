# test-speed

Консольный замер скорости загрузки с указанного HTTP/HTTPS-адреса. Скрипт
последовательно скачивает файл заданное количество раз и выводит среднее время
запроса, общий объём скачанных данных и скорость в **Мбит/с**.

## Установка

Нужен Python **3.10 или новее**.

```bash
git clone https://github.com/glebuzheg/test-speed.git
cd test-speed
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

В Windows используйте `python` вместо `python3`, а для активации окружения
в PowerShell выполните `.venv\Scripts\Activate.ps1`.

## Запуск

Передайте прямую ссылку на большой файл, например картинку. Адрес ниже —
шаблон: замените его реальным URL доступного файла.

```bash
# По умолчанию — 10 запросов.
python speed_test.py "https://example.com/large-image.jpg"

# Другое количество запросов.
python speed_test.py "https://example.com/large-image.jpg" --count 5

python speed_test.py --help
```

`--count` должен быть положительным целым числом. Следующий запрос начинается
только после полного чтения предыдущего ответа. Файл не сохраняется на диск;
тело читается блоками по 64 КиБ, без загрузки всего файла в память.

Иллюстрация вывода для `--count 2` (значения условные):

```text
Запрос 1/2: 10000000 байт, 2.000 с
Запрос 2/2: 10000000 байт, 3.000 с

Среднее время запроса: 2.500 с
Всего скачано: 20000000 байт
Скорость: 32.000 Мбит/с
```

## Запуск в Docker

Если установлен Docker, Python на компьютере устанавливать не нужно.
Из папки проекта соберите образ и передайте ему те же аргументы:

```bash
docker build -t test-speed .
docker run --rm test-speed "https://example.com/large-image.jpg"
docker run --rm test-speed "https://example.com/large-image.jpg" --count 5
docker run --rm test-speed --help
```

Ссылка в примерах — шаблон; замените её реальным URL файла.
Сборка требует доступа к Docker Hub и PyPI. Контейнер удаляется после завершения,
скачанный файл не сохраняется. На macOS и Windows Docker использует виртуальную
машину: её сетевой путь и взаимодействие с VPN/прокси могут отличаться от запуска
скрипта напрямую. `localhost` внутри контейнера обозначает сам контейнер.

## Как считается результат

- Время запроса измеряется через `time.perf_counter()` от начала GET до полного
  чтения ответа, включая установку соединения при необходимости и ожидание сервера.
- Объём — фактически прочитанные байты тела ответа. `Content-Length` не используется
  для подсчёта; сжатое тело учитывается без распаковки. HTTP-заголовки и служебный
  трафик TCP/TLS в объём не входят.
- Среднее время = сумма длительностей / количество запросов.
- Скорость в Мбит/с = сумма байтов × 8 / сумма длительностей / 1 000 000.
  Это скорость всего замера, а не среднее арифметическое скоростей отдельных запросов.

Используется одна `requests.Session`, поэтому соединение может переиспользоваться.
Перенаправления обрабатываются автоматически, проверка сертификатов HTTPS включена.
Запрашиваются несжатые данные (`Accept-Encoding: identity`) и проверка актуальности
кэша (`Cache-Control: no-cache`). Сервер может вернуть сжатый ответ: его байты всё
равно будут подсчитаны без распаковки.

Таймаут соединения и ожидания данных — 30 секунд. Это ограничение сетевого ожидания,
а не общей длительности скачивания: большая загрузка может длиться дольше.
При HTTP-ошибке, таймауте или оборванном ответе скрипт останавливается, пишет
ошибку в stderr и возвращает код `1`, без успешного итога. Некорректные аргументы
дают код `2`, Ctrl+C — `130`, успешный замер — `0`.

## Проверка

После установки зависимостей выполните:

```bash
python -m unittest -v
```

Тесты не обращаются в интернет. Они проверяют аргументы, последовательность
загрузок, формулу, ошибки и загрузку с локального HTTP-сервера: обычный файл,
сжатый ответ, перенаправление, задержку тела после заголовков и обрыв соединения.

## Ограничения

Результат показывает скорость загрузки **с выбранного сервера**. На него влияют
сервер, размер файла, задержки сети, Wi-Fi, VPN, прокси и параллельные загрузки.
Он не гарантирует измерение максимальной скорости подключения. Для более
показательного замера выбирайте достаточно большой файл, который скачивается
несколько секунд. Исходящая скорость не измеряется.

За запуск скачивается файл `count` раз: учитывайте расход трафика.
